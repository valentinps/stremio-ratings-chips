Ratings Chips for Stremio

Adds Rotten Tomatoes, Metacritic, Letterboxd, Trakt… scores and age ratings as a row of chips on the movie/series page, next to Genres and Cast. Stremio only shows one addon's metadata per title, so this addon has to be above Cinemeta in your addon order. Step 4 does that for you.

    This page is served over plain HTTP from a non-local address. Stremio only accepts HTTPS addons (or http://127.0.0.1), so host it behind HTTPS before installing.
    Enter your MDBList key first.
    Install in Stremio app Install on web.stremio.com
    Running locally over http://: Stremio's one-click install links always switch to https:// and drop the port, so they can't reach this server. Instead either copy the URL and paste it into the search box on Stremio's Addons page, or just use Install & move above Cinemeta below, which installs it directly.

    The URL contains your API keys. Don't share it.

    Move it above Cinemeta

    Stremio's UI can't reorder addons, but its API can. This logs in to api.strem.io directly from your browser (nothing goes through this addon's server), installs this addon if needed and moves it to the top. Restart Stremio (or reload web.stremio.com) afterwards.

    Signed in with Google/Facebook? Use an auth key instead

    Open web.stremio.com while logged in, open the browser console (F12) and run JSON.parse(localStorage.getItem("profile")).auth.key. Paste the result here.
